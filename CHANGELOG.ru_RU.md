# История изменений

## 0.2.0-beta — 2026-11-21

### Добавлено

- **Версия для Windows** (Windows 10/11, x64): один `.exe`, которому ничего не нужно
  устанавливать и который использует только DLL самой Windows; собирается
  кросс-компиляцией на Linux с llvm-mingw. Системные функции реализованы через Win32 API,
  как в оригинальном Password Tech: значок в трее с меню и всплывающими уведомлениями,
  глобальные горячие клавиши (`RegisterHotKey`), автонабор (`SendInput`), буфер обмена без
  попадания в журнал и облачную синхронизацию, автозапуск через ключ реестра `Run`,
  «Поверх всех окон», единственный экземпляр, блокировка открытых баз, закреплённые в
  памяти страницы (`VirtualLock`) и даты в региональном формате. Настройки хранятся в
  `%APPDATA%\PwTool`; переносной режим работает как в Linux.
- KDE Plasma на Wayland: «Поверх всех окон», «Сбросить положение окон» и поиск в базе по
  заголовку активного окна работают через скрипты KWin (по D-Bus, без GTK).
- Открытая база и настройки сохраняются при завершении сеанса (выключение Windows или
  выход из системы; в Linux — через монитор сеанса `xdg-desktop-portal`).
- Сборка релиза создаёт `pwtool_<версия>_windows_x64.exe` и перед публикацией запускает
  тесты и консольный режим на Windows-машине.
- **Установщик для Windows** `pwtool_<версия>_windows_x64_setup.exe` (NSIS, русский и
  английский): устанавливает для всех пользователей в `C:\Program Files\PwTool` (права
  администратора запрашиваются только при таком выборе) или для текущего пользователя в
  `%LOCALAPPDATA%\Programs\PwTool`, с ярлыком в «Пуске», по желанию — ярлыком на рабочем
  столе и запуском при входе в систему, и программой удаления в «Приложениях». При
  обновлении сохраняются выбранная папка и настройка автозапуска. Программа удаления
  удаляет настройки только по запросу и никогда не трогает базы паролей. Перед
  публикацией релиза установщик устанавливается и удаляется в тихом режиме в обоих
  вариантах на Windows-машине.

### Изменено

- **Интерфейс больше не использует GTK.** Окна оригинала рисуются с помощью egui по
  описаниям форм оригинала, с той же раскладкой. Пакету для Linux вместо GTK 4 нужны только
  библиотеки C/C++, OpenGL (EGL) и xkbcommon.
- Переводы, список распространённых паролей, примеры скриптов и руководства PDF встроены
  в программу (в сжатом виде); свои переводы по-прежнему можно положить в папку настроек.
- Исполняемые файлы меньше: сборка release с LTO всей программы, одним блоком кодогенерации,
  аварийным завершением при панике и оптимизацией по размеру, кроме криптографии
  (Windows: с 21,7 до 13,8 МБ, Linux: с 29,3 до 18,5 МБ; тест скорости шифров — как
  раньше).
- Цветные варианты значка программы (Настройки > Общие > Значок приложения) сделаны из
  значка Password Tool (tools/make_icon_variants.py), а не из куба Password Tech. В окне
  «О программе» — копирайт автора оригинала без его адреса почты и ниже
  «Copyright © 2026 CoinMan.dev».
- У всех окон один стиль: окна, собранные в коде (выбор шрифта, окна сообщений), берут
  размеры элементов из форм оригинала; поля со списком той же высоты, что поля ввода и
  кнопки, у счётчиков крупные стрелки. Окно выбора шрифта переведено.
- Длинные подписи в переводах занимают свободное место рядом или выводятся чуть меньшим
  шрифтом, а не обрезаются; если подпись всё равно не помещается, полный текст
  показывается во всплывающей подсказке.
- Экранный диктор получает во всех окнах текст подписей, названия кнопок-значков и
  подписи полей ввода; список записей PassCube виден как список с записями и выбранной
  записью (eframe исправлен, чтобы показывать не только главное окно).
- PassCube при вводе имени пользователя предлагает имена из других записей (список под
  полем; выбор стрелками и Enter или щелчком), как в Password Tech.
- Сообщения о том, что на многих системах нормально (нет области уведомлений для значка,
  нет монитора сеанса портала), выводятся только при заданной переменной `PWTOOL_DEBUG`.
- Окна ближе к Password Tech: стрелка редактируемых полей со списком теперь внутри поля
  (её обрезали соседние кнопки); «Создать ▾», «Ещё ▾» и «Выбрать шрифт ▾» — кнопки со
  стрелкой, открывающей их меню; кнопка показа пароля — «•••»; отдельной кнопки сброса
  шрифта больше нет (в меню «Выбрать шрифт» есть «Вернуть стандартный»); окно с
  вкладками шириной ровно по вкладкам. Подписи, уходившие под соседнее поле или за край
  окна (шрифты шире Tahoma, в основном в Linux), выводятся чуть меньшим шрифтом.
- Кнопки и поля с контекстным меню («Создать», «Ещё», поле пароля и др.) в некоторых
  случаях не реагировали на левый щелчок: область правого щелчка больше их не перекрывает.
- Венгерский перевод: у флажков «At least» в построителе набора символов был ошибочный
  текст, перешедший из перевода оригинала.
- Wayland: диалог, нарисованный внутри родительского окна, не больше этого окна (окно
  «Параметры» с большим сохранённым размером обрезалось), а открытие диалога внутри
  PassCube больше не приводит к аварийному завершению с ошибкой протокола Wayland.
- Главное окно больше не обрезается по строке состояния на Wayland при дробном
  масштабировании (eframe принимал монитор 2560x1440 при 125 % за 1280x720).
- PassCube: разделители между списком тегов, списком записей и панелью редактирования
  можно перемещать; список записей заканчивается последним столбцом, а панель
  редактирования сохраняет свою проектную ширину.
- Окно генератора паролей на основе мастер-пароля имеет фиксированный размер (в более
  высоком окне между группами было пустое место); кнопка «Закрыть» в редакторе профилей
  стоит справа.

### Известные ограничения

- Текст нельзя перетащить мышью из программы в другие (копирование и вставка работают).

## 0.1.0-beta — 2026-11-20

Первый публичный бета-пререлиз **Password Tool** (порт Password Tech 3.6.1 на Linux на Rust и GTK4).

### Добавлено

- **Полный генератор паролей**: наборы символов, веса частот, исключение неоднозначных символов, произносимые пароли (триграммы), парольные фразы по спискам слов, шаблоны формата и скрипты Lua.
- **Менеджер паролей PassCube**: двусторонняя совместимость файлов `.pwdb` с Password Tech 3.6.1, мастер-пароль и ключевые файлы, ключ восстановления, теги, предупреждения об истечении срока, история паролей, поля «ключ–значение», импорт/экспорт CSV и резервные копии.
- **Дополнительные инструменты**: мастер-генератор (MP), шифрование текста и буфера обмена, генератор файлов случайных данных, создание файлов триграмм, редактор профилей, пакетная генерация списков паролей и консольный режим.
- **Интеграция с рабочим столом**: значок в трее (StatusNotifierItem), автонабор и глобальные горячие клавиши через `xdg-desktop-portal`, пометка паролей как секретных для Klipper и 13 языков интерфейса.
- **16-сегментный индикатор стойкости пароля** с чёткими цветовыми градациями.
- **Новый логотип и значки приложения** на панели инструментов, в окне «О программе», заголовке окна, трее и меню приложений.
- **Кнопка «Установить по умолчанию»** на одной строке с выбором шрифта интерфейса в «Параметрах».
- **Сборка `.deb`-пакета** с встроенными руководствами `manual.pdf` и `scripting.pdf`.

### Исправлено

- Надёжное открытие локальной документации (`manual.pdf`, `scripting.pdf`) и веб-ссылок через обработчики GIO по умолчанию с резервным переходом на `FileLauncher`/`UriLauncher` и `xdg-open`.
- Исправлены редкие пропуски первого нажатия кнопки **«Создать»**, вызванные кратковременной блокировкой окна при быстрой генерации и перехватом кликов на фазе Capture.
- Исправлен ряд расхождений с оригиналом Password Tech 3.6.1 в криптографии, базах паролей, скриптинге, форматировании и переводах (90 модульных тестов проходят).
