# История изменений

## Не выпущено

### Добавлено

- **Версия для Windows** (Windows 10/11, x64): один `.exe`, которому ничего не нужно
  устанавливать и который использует только DLL самой Windows; собирается
  кросс-компиляцией на Linux с llvm-mingw. Системные функции реализованы через Win32 API,
  как в оригинальном Password Tech: значок в трее с меню и всплывающими уведомлениями,
  глобальные горячие клавиши (`RegisterHotKey`), автонабор (`SendInput`), буфер обмена без
  попадания в журнал и облачную синхронизацию, автозапуск через ключ реестра `Run`,
  «Поверх всех окон», единственный экземпляр, блокировка открытых баз, закреплённые в
  памяти страницы (`VirtualLock`) и даты в региональном формате. Настройки хранятся в
  `%APPDATA%\PwTool`; переносной режим работает как в Linux.
- KDE Plasma на Wayland: «Поверх всех окон», «Сбросить положение окон» и поиск в базе по
  заголовку активного окна работают через скрипты KWin (по D-Bus, без GTK).
- Открытая база и настройки сохраняются при завершении сеанса (выключение Windows или
  выход из системы; в Linux — через монитор сеанса `xdg-desktop-portal`).
- Сборка релиза создаёт `pwtool_<версия>_windows_x64.exe` и перед публикацией запускает
  тесты и консольный режим на Windows-машине.

### Изменено

- **Интерфейс больше не использует GTK.** Окна оригинала рисуются с помощью egui по
  описаниям форм оригинала, с той же раскладкой. Пакету для Linux вместо GTK 4 нужны только
  библиотеки C/C++, OpenGL (EGL) и xkbcommon.
- Переводы, список распространённых паролей, примеры скриптов и руководства PDF встроены
  в программу; свои переводы по-прежнему можно положить в папку настроек.
- Длинные подписи в переводах занимают свободное место рядом или выводятся чуть меньшим
  шрифтом, а не обрезаются; если подпись всё равно не помещается, полный текст
  показывается во всплывающей подсказке.
- Экранный диктор получает в главном окне текст подписей, названия кнопок-значков и
  подписи полей ввода.

### Известные ограничения

- Текст нельзя перетащить мышью из программы в другие (копирование и вставка работают);
  в PassCube нет автодополнения имени пользователя.
- Окна, кроме главного, экранный диктор видит только по заголовку.

## 0.1.0-beta — 2026-11-20

Первый публичный бета-пререлиз **Password Tool** (порт Password Tech 3.6.1 на Linux на Rust и GTK4).

### Добавлено

- **Полный генератор паролей**: наборы символов, веса частот, исключение неоднозначных символов, произносимые пароли (триграммы), парольные фразы по спискам слов, шаблоны формата и скрипты Lua.
- **Менеджер паролей PassCube**: двусторонняя совместимость файлов `.pwdb` с Password Tech 3.6.1, мастер-пароль и ключевые файлы, ключ восстановления, теги, предупреждения об истечении срока, история паролей, поля «ключ–значение», импорт/экспорт CSV и резервные копии.
- **Дополнительные инструменты**: мастер-генератор (MP), шифрование текста и буфера обмена, генератор файлов случайных данных, создание файлов триграмм, редактор профилей, пакетная генерация списков паролей и консольный режим.
- **Интеграция с рабочим столом**: значок в трее (StatusNotifierItem), автонабор и глобальные горячие клавиши через `xdg-desktop-portal`, пометка паролей как секретных для Klipper и 13 языков интерфейса.
- **16-сегментный индикатор стойкости пароля** с чёткими цветовыми градациями.
- **Новый логотип и значки приложения** на панели инструментов, в окне «О программе», заголовке окна, трее и меню приложений.
- **Кнопка «Установить по умолчанию»** на одной строке с выбором шрифта интерфейса в «Параметрах».
- **Сборка `.deb`-пакета** с встроенными руководствами `manual.pdf` и `scripting.pdf`.

### Исправлено

- Надёжное открытие локальной документации (`manual.pdf`, `scripting.pdf`) и веб-ссылок через обработчики GIO по умолчанию с резервным переходом на `FileLauncher`/`UriLauncher` и `xdg-open`.
- Исправлены редкие пропуски первого нажатия кнопки **«Создать»**, вызванные кратковременной блокировкой окна при быстрой генерации и перехватом кликов на фазе Capture.
- Исправлен ряд расхождений с оригиналом Password Tech 3.6.1 в криптографии, базах паролей, скриптинге, форматировании и переводах (90 модульных тестов проходят).
